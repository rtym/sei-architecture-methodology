# BG-3: Keep feature pace with competitors

- **Statement**: Engineering needs to ship new report types weekly so that the product keeps pace with competitor feature velocity.
- **Primary stakeholder**: ST-2 — Eng lead
- **SEI business-goal category**: process quality
- **Measure of success**: ≥ 1 new report type released per week, sustained
- **Priority**: high
- **Status**: open

## Context

Early-stage SaaS; this goal is one of the four the architecture must serve. See
[`../README.md`](../README.md) for the full driver set and traceability.

## Supported by

- Use cases: [UC-1](../use-cases/UC-1.md)
- Quality attribute scenarios: [MQA-1](../quality-attributes/MQA-1.md)

## Notes

Velocity is in tension with [CON-2](../constraints/CON-2.md) (one engineer) — that tension is
itself an architectural driver. MQA-1 (add a report type in ≤ 1 person-day, 0 regressions) is
the measurable expression of this goal.
